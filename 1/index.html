首次使用？3 分钟配置指南（点我展开）
  1. 打开 supabase.com 用 GitHub 账号登录，点 New Project 免费建库（免费额度：500MB 数据库、无限 API 请求）。
  2. 左侧 SQL Editor 粘贴并执行下面这段 SQL（建一张密文表）：
create table if not exists public.vault (
  id bigint generated by default as identity primary key,
  slot text unique not null,
  blob text not null,
  updated_at timestamptz not null default now()
);
alter table public.vault enable row level security;
create policy "vault full access"
  on public.vault for all using (true) with check (true);
  1. 到 Project Settings → API，复制 Project URL 和 anon public key 粘到上方。
